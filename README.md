# درسیار — Darsyar

**A beautiful, Persian study companion that lives in a single HTML file.**

Focus timer · daily goal · streaks · 12-week heatmap · shareable progress card.
No sign-up, no server, no install — your data never leaves your browser.

**▶ Use it now: https://ali30mhi.github.io/Darsyar/**

## Features

- **Focus timer** — Pomodoro-style sessions (50 + 10 minutes by default),
  with a progress ring, sound and desktop notification when a session ends
- **Subjects** — add your courses; every session is logged per subject
- **Daily goal** — progress bar towards your study goal for the day
- **Streaks** — 🔥 current streak and 🏆 best streak
- **12-week heatmap** — see your consistency at a glance (GitHub-style)
- **7-day breakdown** — how your time was split between subjects
- **Progress card** — one tap creates an image of today's stats to share
  on Telegram, Instagram or WhatsApp
- **Made for Persian users** — right-to-left layout, Jalali (Shamsi)
  dates, Persian digits, weeks starting on Saturday
- **Reliable** — the timer survives page reloads and background tabs,
  multiple tabs stay in sync, invalid input and corrupted backups are handled
- **Private** — everything is stored in `localStorage`; backup and restore
  as a JSON file
- **Zero dependencies** — one `index.html`, works offline

## Run locally

Just open `index.html` in any modern browser.

## Host it for free

Settings → Pages → *Deploy from a branch* → `main` / `(root)` → Save.
Your app will be live at `https://<username>.github.io/Darsyar/`.

## Keyboard

`Space` — start / pause the timer
